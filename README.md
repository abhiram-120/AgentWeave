# Multi-Agentic Chat System

## Overview

The **Multi-Agentic Chat System** is an advanced AI-powered application that leverages multiple specialized agents to process user queries and provide structured, insightful responses. The system uses the **Claude AI API** for user interaction and reasoning tasks, and the **Gemini API** for data-intensive operations, such as research and creative tasks. This project demonstrates a robust multi-agent architecture designed to solve complex problems collaboratively.
